# Семейный бюджет

Сайт для семейного учёта: доходы и расходы, будущие покупки и накопления на цели. Сначала открывается короткий приветственный экран, из него — рабочий бюджет.

## Как открыть

Откройте файл `index.html` двойным щелчком в браузере. Устанавливать зависимости и запускать сервер не нужно.

## Что умеет сайт

- Приветственный экран с кратким описанием и цифрами уже сохранённых записей.
- Бюджет за выбранный месяц или за весь период.
- Добавление и удаление доходов и расходов.
- Список будущих покупок и отметка «выполнено».
- Финансовые цели: нужная сумма, пополнение и прогресс.

Все записи остаются в `localStorage` этого браузера. Другой компьютер и другой браузер их не увидят.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Сайт: приветствие и весь функционал |
| `Семейный_бюджет_обновленный.html` | Предыдущая рабочая версия без приветственного экрана |
| `бюджет +накопления.html` | Более ранний черновик |
| `семейный бюджет.html` | Первый черновик, в нём есть переключение светлой и тёмной темы |
